# Mini-projects 
This repository showcases a collection of analytical mini-projects completed to build foundational skills in data analysis, database management, and statistical modeling. Each mini-project addresses a distinct analytical challenge, demonstrating proficiency in SQL-based data operations and clustering analysis.

### 1. E-Commerce Data Analysis
- **Objective:** The objective of this mini project is to practice SQL skills by working with an e-commerce dataset. 
- **Skills Demonstrated:** Database creation and management, data insertion, data retrieval, data aggregation, and data filtering
- **Tools/Libraries Used:** SQL, MySQL Workbench

### 2. Electronics Database Analysis
- **Objective:** This repository contains a set of SQL queries used to analyze and retrieve data from the electronicsdb database.
- **Skills Demonstrated:** table joins, data aggregation, conditional filtering
- **Tools/Libraries Used:** SQL, MySQL Workbench

### 3. Heart Disease Clustering
- **Objective:** This project explores clustering within the Heart Disease Dataset by standardizing numerical attributes and applying the K-Means clustering algorithm.
- **Skills Demonstrated:** Data preparation, data standardization, statistical analysis, K-Means clustering, and data visualization
- **Tools/Libraries Used:** SAS
