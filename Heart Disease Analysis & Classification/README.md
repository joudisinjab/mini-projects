# Heart Disease Analysis & Clustering

Welcome to the repository dedicated to K-Means clustering and analysis performed on the Heart Disease Dataset. This analysis employs standardization, K-Means clustering, and visualization techniques in SAS to identify optimal patient clusters.

---
## Project Overview

This project explores clustering within the Heart Disease Dataset by standardizing numerical attributes and applying the K-Means clustering algorithm. Various cluster counts (k = 2 to 6) were evaluated to identify the optimal number of clusters using RMS standard deviation and R-squared metrics. The goal was to discover inherent groupings among patients based on health attributes, ultimately aiding in better understanding patient classification and risk stratification.

---
### Tasks

1. Data Import and Initial Exploration: Imported the dataset using SAS procedures and performed an initial exploration to inspect the data structure.
2. Basic Data Analysis: Conducted statistical analysis using PROC MEANS to summarize key characteristics.
3. Data Standardization: Standardized numerical attributes with PROC STDIZE to prepare the data for clustering.
4. K-Means Clustering: Applied the FASTCLUS procedure for clustering at different cluster counts (k=2, 3, 4, 5, 6), generating scatter plots to visualize clusters.
5. Optimal Cluster Determination: Analyzed clustering results to determine the best number of clusters (k=5) using RMS standard deviation and R-squared metrics.

---
### Skills Demonstrated

1. Data Preparation and Standardization: Using SAS PROC STDIZE for scaling numerical data for clustering.
2. Statistical Analysis: Employing PROC MEANS for descriptive statistics.
3. Clustering Techniques: Implementing K-Means clustering with PROC FASTCLUS, evaluating cluster cohesion and separation through RMS standard deviation and R-squared.
4. Data Visualization: Creating scatter plots and line plots in SAS for effective interpretation and communication of clustering results.
5. Analytical Interpretation: Utilizing the elbow method for selecting the optimal number of clusters, interpreting metrics clearly and effectively.
